# K8 5W 홈 테마 0.4.7 실차 체크리스트

차량 연결이 없을 때 만들어 둔 시험 묶음과 확인 목록이다. 연결되면 아래 순서대로 한 번에 확인한다.
스크립트는 `tools/field_test_0.4.7.sh`(Git Bash), 주소는 `K8_ADDR` 환경변수나 `private/k8-addr` 파일에 둔다.

## 준비

```text
cd "C:/AI 통합/네메시스/research/k8-ccnc-home-theme"
export K8_ADDR=차량IP:5555
bash tools/field_test_0.4.7.sh status
bash tools/field_test_0.4.7.sh install
```

- 설치는 0.4.6과 같은 서명이므로 지우지 않고 덮어쓴다. 저장된 사진·바로가기·설정은 남는다.
- 스크린 조작 시험은 반드시 정차 상태에서 한다. 스크립트가 속도 로그를 보고 주행 중이면 중단한다.

## 1. 시동 후 자동 실행

| 확인 | 방법 | 통과 기준 |
|---|---|---|
| 부팅 수신기가 등록됐나 | `status`의 부팅 수신기 부분 | `BootReceiver`가 `BOOT_COMPLETED`로 표시 |
| 부팅 방송을 받으면 예약되는가 | `adb logcat -s K8HomeBoot` | `launch scheduled in 22000 ms` |
| 예약 뒤 테마가 열리나 | `bash tools/field_test_0.4.7.sh boot` | 22~30초 뒤 맨 위 창이 `io.github.k8home` |
| 카메라·안전 화면이 먼저 뜨면 기다리는가 | 리버스 후 리모트 줌(후방 화면) 확인 | 카메라가 닫힌 뒤에 테마가 뜬다 |
| 완전 부팅과 QuickBoot 각각 | 차량에서 완전 재시작, 그다음 빠른 재시작 | 두 경우 모두 같은 결과 |
| 끌 수 있나 | 앱 설정 > 일반 > `시동 후 자동 실행` 끄기 → 재시작 | 꺼진 상태에서는 테마가 자동으로 열리지 않는다 |

- `K8HomeBoot` 로그의 `launching the theme home`이 없으면 예약이 아니라 다른 경로로 열린 것이다.
- 카메라가 화면에 남은 상태에서 테마가 뜨면 화면 덮어쓰기 문제가 있다. 그 경우 이 항목을 미완료로 기록한다.

## 2. 물리 HOME 버튼

| 확인 | 방법 | 통과 기준 |
|---|---|---|
| HOME 카테고리 등록 | `bash tools/field_test_0.4.7.sh home` | `pm query-activities` 결과에 `io.github.k8home` |
| HOME 인텐트 실행 | 위 스크립트가 `am start` 실행 | 맨 위 창이 테마 |
| 차량 물리 HOME 버튼 | 차량 HOME 버튼을 누른다 | 테마가 열리거나, 선택창(chooser)이 뜨고 테마가 선택됨 |
| 선택창이 뜨는가 | HOME 버튼 반복 | 뜨면 순정 런처와 테마 중 고를 수 있는 상태인지 확인 |

- 안티 팝업(선택창)이 뜨는 것은 안드로이드 4.4의 기본 동작이다. 테마만 남기려면 차량 런처를 제거하거나,
  앱 안의 `차량 홈 화면 설정` 버튼으로 시스템 홈 설정에 들어간다.

## 3. 순정 내비 위 하단바

기본값은 높이 90 px, 위치 하단, 아래 여백 0 px다. 순정 5W 내비의 하단 줄(메뉴 · 경로 종료 · 남은 거리 · 도착 시간)을 덮고 그 자리에 ccNC 하단바가 놓인다.

| 확인 | 방법 | 통과 기준 |
|---|---|---|
| 내비 위에 바가 뜨나 | `bash tools/field_test_0.4.7.sh navbar` | `dumpsys window windows`에 `K8HomeNavBar` |
| 순정 하단 줄이 안 보이는가 | 스크린샷 확인 | 순정 줄이 우리 바 아래로 숨겨진다 |
| 길안내 정보가 오나 | 내비에서 길안내 중 | 중앙 알약에 남은 거리·시간·목적지 이름이 나온다 |
| 경로 종료 | 중앙 알약의 ✕ | 길안내가 취소된다 |
| 내비 메뉴 | ≡ | 순정 내비 메뉴가 열린다 |
| 목적지 정보 | ⓘ | 목적지 정보가 열린다 |
| 테마 안의 하단바와 같은 모습인가 | 스크린샷 비교 | 뒤로·홈·전체 메뉴 키, 가운데 알약, 오른쪽 미디어 상자가 테마와 같다 |
| 다른 화면에서도 남나 | 설정·전화·카메라 화면으로 이동 | 내비 밖에서는 사라져야 한다 |
| 홈 버튼 | 바의 홈 키 | 테마 홈으로 이동 |
| 전체 메뉴 | 바의 ≡ 키 | 순정 내비 메뉴가 열린다. 테마 안의 ≡ 와는 뜻이 다르다 |
| 뒤로 | 바의 뒤로 키 | 3분 동안 다시 뜨지 않는다 |
| 재생·일시정지 | 바의 미디어 상자 | 곡 정보가 바뀌고 상태가 유지 |
| 곡 제목 | BT 또는 USB 재생 중 | 바 오른쪽에 곡 제목·가수 |
| 위치·높이 조정 | 바를 길게 누름 | 상단/하단 전환과 높이 64/90/112 px, 아래 여백 0/44/90/140 px 선택 |
| 권한 거부 | `adb logcat -s K8HomeNavBar` | `overlay window was refused`가 뜨면 차량이 오버레이를 막은 것 |

- 기본은 높이 90 px, 위치 하단, 아래 여백 0 px다. 순정 5W 내비의 하단 줄(메뉴 · 경로 종료 · 남은 거리 · 도착 시간)을 덮는다.
- 순정 줄을 덮은 뒤 **순정 내비의 출구 버튼**을 못 누르게 될 수 있다. 내비 안의 다른 길로 나가야 한다.
- 길안내 정보가 안 나오면 `adb logcat | grep Route_Guide`로 내비 방송이 도는지 먼저 본다. 방송은 오는데 화면이 안 바뀌면 extras 이름이 다르다는 뜻이다.
- 오버레이가 아예 안 뜨면 `SYSTEM_ALERT_WINDOW` 권한 문제다. 차량 빌드에서 이 권한이 허용되는지 확인해야 한다.
- 바가 뜨긴 하는데 글자가 깨지거나 비어 있으면 WebView가 뜨지 않은 것이다. `adb logcat -s chromium`을 확인한다.

## 4. 되돌리기

```text
bash tools/field_test_0.4.7.sh restore
```

- 앱 안에서 `시동 후 자동 실행`과 `순정 내비 위 하단바`를 끈다.
- 완전 제거가 필요하면 `adb -s 차량IP:5555 uninstall io.github.k8home`.
- 부팅 자동 실행이 불편하면 `adb shell pm disable io.github.k8home/.BootReceiver`로 수신기만 잠시 끌 수 있다.
