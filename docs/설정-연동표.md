# 5W 설정을 ccNC 테마 안으로 옮기는 연동표

2026-11-22. K8(기아) 5W 헤드유닛에 있는 순정 설정 항목을 ccNC 모양 화면에서 보고 바꾸기 위한
연동 조사표다. **5W 설명서(https://ownersmanual.kia.com/ivi/STD_GEN5W/AVNT/KOR/Korean/ 설정 장)** 를
기준으로 "사용자 차에 실제로 있는 항목"만 담았다. ccNC 설명서(https://ownersmanual.kia.com/ivi/ccNC/AVNT/KOR/Korean/)
의 분류·화면 배치를 기준으로 한다.

## 읽는 법

| 항목 | 뜻 |
|---|---|
| 상태 **확인됨** | 차량 파일(분해 결과·매니페스트) 또는 우리 코드가 이미 쓰고 있는 경로에서 근거가 있다 |
| 상태 **추정** | 이름·구조가 맞아 보이지만 실제 키나 호출을 아직 확인하지 못했다. 차에서 한 번 확인해야 한다 |
| 상태 **불가** | 일반 앱(우리가 설치한 앱)로는 읽거나 쓸 수 있는 경로를 찾지 못했다 |

- **읽기 경로** 표에 적힌 대로면 테마에서 값을 보여 줄 수 있다.
- **쓰기 경로**가 "없음"인 항목은 이번 단계에서 값을 바꾸지 않는다(순정 화면으로 연결만 한다).
- 상태가 **추정**인 줄에는 반드시 "추정"을 적었다. 근거 없는 메서드·키 이름을 지어내지 않았다.

## 0. 사실로 먼저 확인한 것 (근거)

| 사실 | 근거 |
|---|---|
| 순정 설정 앱 `com.hkmc.system.app.homesetting` 는 **시스템 계정(android.uid.system)** 으로 돈다 | `private/vehicle/com.hkmc.system.app.homesetting/HKMC_HomeSetting_WP.apk` 매니페스트 `android:sharedUserId="android.uid.system"` |
| 그 앱의 **HomeSettingProvider 는 exported=true 이고 권한 제한이 없다** | 같은 매니페스트: authority `com.hkmc.system.app.homesetting.provider`, `exported="true"`, permission 없음 |
| 순정 설정 앱은 **코드가 없는 APK**다(리소스만 있음, 실제 코드는 차량 `/system/app/HKMC_HomeSetting_WP.odex`) | APK 안에 classes.dex 없음. JADX 분해 결과 java 파일 1개(리소스 R.java) |
| 그래서 **순정 설정 앱 안의 저장소 키는 아직 못 읽었다** | 위와 같은 이유. 5W 설정 항목별 키는 대부분 추정 단계다 |
| 앰프(사운드) 설정은 **차량 서비스 AIDL** 로 되어 있고 메서드 이름이 공개돼 있다 | `k8-ambient-sync/private/oem-sml-analysis/smali-automotive/com/hkmc/media/IMicomAudioService.smali` |
| 버튼 설정 앱은 `com.android.buttonsettings`, 블루투스 설정은 `com.android.btsettings`, 화면구성은 `com.android.themesettings` | `k8-ccnc-theme-seogaemo/upstream/hmg-seogaemo/core/hookpoints/*.json` 의 `files` 항목 |
| 우리 앱에는 `WRITE_SETTINGS` 권한이 **없다** | `AndroidManifest.xml` uses-permission 목록 |

> **중요(검수 때 고침)**: 이 차는 안드로이드 4.4(API 19)다. 4.4에서 `Settings.System` 쓰기에 필요한 `WRITE_SETTINGS` 는
> 서명 권한이 아니라 설치할 때 주어지는 권한이라, 매니페스트에 넣기만 하면 일반 앱도 받을 수 있다(차에서 확인 필요).
> 지금은 일부러 넣지 않았으므로 쓰기는 **안 된다.** `Settings.Global`/`Settings.Secure` 쓰기는 `WRITE_SECURE_SETTINGS`(서명 권한)라 일반 앱으로는 안 된다. 읽기는 대부분의 키가 된다. 쓰기는 (1) 차량 서비스 AIDL 호출이나 (2) NEMESIS 의 root 도우미를
> 통해서만 가능하며, 3단계에서는 스위치가 꺼져 있는 동안 아예 호출하지 않는다.

> **0.5.0-test1 에서 한 일**: 사운드 항목의 읽기 경로를 `MicomAudioStatus` 필드로 넓혔다
> (`mTreble/mMiddle/mBass/mFade/mBalance/mSDVC/mSoundPriority/mAutoAdjustingVolumeSetting/
> mDimVolumeInReverse/mNaviDuringCall/mBeepMode/mSurround/mBoseCPMode/mMeridianHorizonMode/mQLS/
> mLiveDynamic/mEqMode/mVariableEqMode/mIsRearSleepOn/mPowerTreble/mVolume/mAsl`).
> 테마의 사운드 화면은 이 값을 **읽기 전용**으로 보여 준다(0/1 항목은 켜짐/꺼짐으로 표시).
> 앰프 값의 실제 단위와 어떤 값이 뭔지는 **차에서 확인해야** 확정된다.

## 1-1. 사운드 화면(0.5.0-test7 적용)

- 메뉴 11개는 **5W 에 있는 것만** 남겼다: 고급 음향 · 전후/좌우 · 고음/중음/저음 · 안내음 · 화면 터치음 ·
  서라운드 · 후석 취침 모드 · 라디오 음질 · 운전자 보조 · 연결 기기 + 테마 기능(미디어 음량).
- 값은 **숫자(단계) 그대로** 보여 준다. 켜짐/꺼짐으로 바꾸지 않는다. 못 읽는 항목은 "순정 연동 대기".
- 읽는 키: `soundTreble` `soundMiddle` `soundBass` `soundFade` `soundBalance` `soundSdvc` `soundAutoVolume`
  `soundAsd` `soundPowerTreble` `soundEqMode` `soundVolume` `soundPriority` `soundNaviDuringCall`
  `soundRearSleep` `soundReverseDim` `soundBeepMode` `soundSurround`.
- ccNC 안내음 화면에만 있는 "음성 변경" 세그먼트(밝은 어항 음성/부드러운 남성 음성)는 읽는 값이 없어
  "순정 연동 대기"로 둔다.

## 9-1. 버튼 값 번호 ↔ 선택지 대응 (0.5.0-test3 조사 결과: **대응 미확인**)

- `com.android.buttonsettings` 앱의 리소스(문자열 배열)에 선택지 목록이 들어 있으나,
  **그 앱 APK·odex 를 PC 에 가지고 있지 않다.** 차량 `/system/app/ButtonSettings.apk`(3,100,204 바이트)와
  `ButtonSettings.odex`(3,334,096 바이트)가 있다는 것까지만 차량 캡처 목록(`51-system-files.txt`)에서 확인했다.
- `k8-ccnc-theme-seogaemo` 훅포인트(`.agents`/`core/hookpoints/buttonsettings.json`)에서 확인한 클래스 구조:
  `com.android.buttonsettings.CustomButtonSetting`(ListActivity) · `mMenuList`(ArrayList) · `mCurList`(List) ·
  `mCheckedList`(boolean[]) · `mKeycode`(String) · `initList()` · `initCustomKey()` · `setSelectedIdem(int)` ·
  `getListItem(int, String, int)` · 어댑터 `IconTextListAdapter.setListItems(List)`.
  → 선택지 배열은 `mMenuList` 에서 오고 선택 위치는 `setSelectedIdem(int)` 로 저장되는 **구조**는 확인했으나,
  **어떤 int 값이 어떤 선택지인지**는 APK/odex 없이는 확인할 수 없다.
- **그래서 테마에서는 현재 선택된 라디오를 표시하지 않는다.**(지어내지 않기)
  대신 값 번호(`순정 값 N`)만 보여 주고, 대응은 차에서 확인하는 것으로 남긴다.

## 10. 차에서 한 번만 확인하면 확정되는 것

차에 가지 않고는 **저장소 키와 권한**을 확인할 수 없다. `docs/설정-차시험.md` 순서대로 한 번에 확인한다.

1. 순정 설정 화면을 각 분류별로 열어 **저장되는 키**를 `settings get system|secure|global <키>` 로 확인
2. `Settings.System` 쓰기가 우리 uid 로 되는지(`WRITE_SETTINGS` 없이는 안 됨) 확인
3. 앰프 AIDL(`IMicomAudioManager`) 호출이 일반 uid 에서 되는지 확인
4. `com.hkmc.system.app.homesetting.provider` 가 어떤 값을 주는지 확인
5. **버튼 선택지 대응**: `adb pull /system/app/ButtonSettings.apk` 와 `ButtonSettings.odex` 를 받아
   `mMenuList` 의 문자열 배열과 `btn_n_left`/`btn_n_right`/`button_settings_seek`/`tune_knob_function` 의
   int 값 대응을 확인한다(문자열 배열 순서가 곧 선택지 번호일 가능성이 높다).

## 9. 0.5.0-test9 값 읽기와 화면 목록 교체 (2026-11-22)

이번에 한 것은 **읽기**뿐이다. 쓰기 코드와 새 권한은 추가하지 않았다.
근거는 `docs/5W-순정설정-실차수집.md` 의 "테마가 읽을 수 있는 순정 설정 키" 표와
수집한 화면 요약(✔ 표시)다. 근거가 없는 값은 글자로 바꾸지 않고 "순정 값 N"으로 보여 준다.

### 9.1 새로 읽는 순정 설정 키

`HeadUnitInfo.java` 가 읽는다. 키 뒤에 `_dr{운전자}` 가 붙은 것은 현재 운전자(`user_profile_driver`) 번호로 붙여 읽고,
없으면 접미사 없는 키를 본다. 읽는 곳은 system → global → secure 순서다.

- 정수(34개): `sound_mute_nav_guide` `use_welcome_message` `voice_type_information` `kakao_friends_voice_information`
  `vr_enable_wakeup` `vr_enable_bargein` `rear_voice_recognition_lock` `bluelight_enable` `bluelight_mode` `bluelight_level`
  `keep_last_mode` `media_notification` `time_12_24` `gps_auto_time` `summer_time` `vol_tuneknob_swap` `tune_knob_function`
  `button_settings_seek` `sound_position_mode` `sound_position_seat` `rear_sleep_mode` `daylight_bright` `night_bright`
  `split_screen_on` `waiting_display_type` `clock_widget_type` `analog_clock_type` `rear_camera_option` `camera_bright_setting_day`
  `media_repeat_folder` `androidauto_ss_osd` `carplay_ss_osd` `sound_rnc` `sound_adp_anc`
- 접미사 없는 정수(3개): `video_aspect_ratio` `drivemode_notification` `seat_position_alert`
- 문자열(3개): `bluelight_starttime` `bluelight_endtime` `language_type`
- 톤(3개): `hkmc_sndset_treble_USER_{운전자}` `hkmc_sndset_middle_USER_{운전자}` `hkmc_sndset_bass_USER_{운전자}`
  (10을 0으로 저장한다. 화면에는 10을 뺀 수로 보여 준다: 14 → +4, 10 → 0, 20 → +10)
- 오디오 음량 자동 줄이기(1개): `hkmc_sndset_auto_adjusting_vol_USER_{운전자}`
- 사용자 버튼·MODE 버튼은 **설정 키가 아니라 시스템 속성**이다.
  `persist.sys.key.custom` `persist.sys.key.swrccustom` `persist.sys.key.mode`

앰프 상태 객체(`MicomAudioStatus`)의 값과 설정 키 값이 다르면 **설정 키 쪽 값을 쓰고** `K8Settings` 태그로 로그를 남긴다.
