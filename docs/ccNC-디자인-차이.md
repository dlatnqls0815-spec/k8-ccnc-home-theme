# ccNC 공식 매뉴얼 대비 차이 (2026-11-21, Claude)

기준: 기아 ccNC 한국어 매뉴얼 이미지 17개(홈, 전체 기능 넘기기·재배치 GIF, 하단 메뉴, 지도, 블루투스 오디오 3장, 최근 통화, 퀵 컨트롤 GIF, 분할 화면 GIF 3개, 화면구성 4장).
우리 화면: 0.4.22 `assets/index.html`을 1920×720 Edge로 캡처(시험 데이터). 매뉴얼 그림은 약 945×354 축소본이라 픽셀 단위가 아닌 눈 비교다.

## 홈

- 배경: 공식은 검정. 우리는 기본값이 5W 개조 영상의 **파란 배경**(`bgMode: 'blue'`). 설정으로 검정 선택 가능.
- 카드 테두리: 공식 카드는 얇은 밝은 테두리가 있다. 우리는 없음.
- 미디어 카드: 공식은 **왼쪽 정사각형 앨범 그림** + 아래 제목·부제. 우리는 카드 윗부분 전체를 채우는 그림 + 왼쪽 위 `미디어` 꼬리표 + 진행선. 꼬리표·진행선은 공식에 없다.
- 지도 카드 아래 줄: 공식은 `▲ 서울시 서초구 부근`(현재 위치). 우리는 경로 없을 때 0.4.21부터 현재 도로명을 받으면 표시.
- 맨 위 오른쪽: 우리만 `BT 상태 대기` 글자가 있다.
- 맨 아래: 공식은 페이지 점 4개뿐. 우리는 `‹ 배경화면`, `전체 메뉴 ›` 글자, 점 5개, `5W 파란배경`·`화면구성` 버튼이 더 있다.

## 전체 기능(앱 카드)

- 카드 색: 공식은 모두 **같은 짙은 회색 단색**, 위 70% 밝은 칸 + 아래 30% 어두운 칸. 우리는 카드마다 색(초록·보라·갈색…)과 대각선 줄무늬.
- 모서리: 공식은 왼쪽 위와 오른쪽 아래가 잘린 모양. 우리도 같지만 잘린 크기가 다르다.
- 우리만 `● 연결됨` 꼬리표, `아이콘 재배치` 버튼, `다음 페이지 ›` 글자가 있다.
- 길게 눌러 옮길 때: 공식은 잡은 카드만 약간 밝아진다(그림자·확대 없음).

## 블루투스 오디오

- 공식 화면에는 분할 화면이 없고, 오른쪽에 큰 앨범 그림 + 그 아래 ◀ ⏸ ▶가 있다. 우리는 분할 화면 때문에 앨범과 버튼이 가운데로 작게 밀렸다.
- 아래 소스 줄: 공식은 **아이콘만**(글자 없음), 선택된 것은 초록 사각형. 우리는 아이콘 + 글자(`자연의 소리`, `블루투스`, `FM`…)와 넓은 초록 칸.
- 왼쪽 기기 상자: 우리만 `목록 / 한 곡 / 플레이어` 버튼이 있다.
- 재생 목록: 공식은 번호 + 곡명만. 우리는 가수·시간까지, 그리고 블루투스 목록 안에 자연의 소리·FM이 섞인 시험 데이터.
- 플레이어 화면(공식): 왼쪽 위 `⌄ 블루투스 오디오`, 기기 이름, 큰 곡명, 가수, 앨범, ◀ ⏸ ▶, 아래 진행선, 오른쪽 `♪ 1/6`과 목록 아이콘. 우리 화면에서는 이 배치를 확인 못 함(버튼으로만 전환).

## 전화(최근 통화)

- 아래 탭: 공식은 **아이콘만** 5개. 우리는 아이콘 + 글자(`최근 통화`, `연락처`…).
- 이름 글자: 공식은 보통 굵기·작게. 우리는 굵고 크다.
- 공식은 분할 화면 없이 오른쪽에 휴대폰 그림 + `Phone Name`.

## 퀵 컨트롤

- 공식에는 `퀵 컨트롤` 제목 글자가 없다(왼쪽 위 `⌃`, 오른쪽 위 ⚙만).
- 칸 배치: 공식은 3열 중 오른쪽 열 아래가 비어 있다. 우리는 모든 열이 화면 아래까지 꽉 찬다.

## 분할 화면

- 여는 방법: 공식은 **하단 오른쪽 미디어 상자를 누르거나 위로 밀면** 그 바로 위에 좁은 위젯이 열린다. 오른쪽으로 밀면 닫힌다. 우리는 화면 오른쪽 끝 `›` 손잡이.
- 크기: 공식 위젯 너비는 하단 미디어 상자와 같다(화면의 약 22%). 우리는 더 넓다.
- 머리줄: 공식은 제목·버튼 없음. 우리는 `지도` 제목과 ▲ ▼ ⚙ 버튼.
- 페이지 화살표 ‹ ›: 공식은 손을 댈 때만 나타난다. 우리는 항상 보인다. 점 표시는 같다.

## 화면구성 설정

- 분할 화면: 공식은 줄마다 오른쪽 `≡`(끌어서 순서 바꾸기)만. 우리는 ▲ ▼ 버튼이 더 있다. 공식은 `지도` 체크가 흐리게(항상 켜짐, 못 끔). 우리는 다른 줄과 같은 색.
- 클러스터 테마: 공식 안내문 `선택된 테마로 표시합니다.` / `클러스터 게이지의 스타일을 선택합니다.` / `클러스터 및 홈 화면의 그래픽 스타일을 선택합니다.` 우리는 문장을 바꿔 썼다. 오른쪽 그림도 공식은 화면 두 장이 겹치는 그림, 우리는 게이지 그림.
- 대기 화면: 공식 톱니 아이콘이 더 크다. 오른쪽 그림은 두꺼운 테두리의 검은 사각형.
- 디지털 액자: 공식은 줄 끝에 `›`. 우리는 `선택` 글자. 안내문도 다름(공식: `대기 화면과 분할 화면에 휴대폰 앱에서 업로드한 이미지가 표시됩니다.`). 오른쪽 그림은 공식이 액자 모양 그림.

## 지도(순정 내비 위 하단바)

- 경로가 없을 때 공식 하단 가운데는 `▲ 서울 서초구 부근`(현재 위치). 우리 `navbar.html`은 `목적지 검색`. 0.4.21의 현재 위치 응답을 쓰면 맞출 수 있다.
