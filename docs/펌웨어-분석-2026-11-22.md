결론: 두 펌웨어 모두 화면 리소스·앱을 꺼낼 수 없다. 5W 앱은 차에서 이미 뽑아 둔 평문 파일(`private/vehicle`, `k8-easy-access/private/sys/fw`, `k8-ambient-sync/private/nowplaying/apps`)로 분석한다. ccNC 디자인은 공식 매뉴얼 그림, 실차 사진·영상 기준을 유지한다.

ccNC 오픈소스 고지(`Open Source S_W License Notice_ccNC_R10`)로 본 ccNC 구성: 리눅스(NVIDIA Tegra, Wayland, GStreamer) + Chromium 120 + 안드로이드 구성요소. 글꼴은 Google Noto Fonts, DejaVu, Liberation, Tinos, Source Code Pro 등 공개 글꼴이 들어 있다(한글 주 글꼴은 고지에 없음 → 독자 글꼴일 가능성).

## 5W에서 새로 찾은 통로

### 1. 순정 분할 화면용 내비 화면 (0.4.26에 연결)
- 순정 `RightScreenHome`(분할 화면)은 회전 정보를 받지 않는다. 자기 화면(Surface)을 내비 `com.mnsoft.navi/.InterfaceService`에 넘기면 **내비가 지도·경로·회전 화살표를 직접 그려 준다.**
- `InterfaceService`는 `exported=true`, 권한 없음. 내비 쪽 `onTransact`에 호출자 확인 없음.
- 호출 번호(`com.mnsoft.navi.IInterfaceService`, 두 앱 odex에서 대조):
  - 1 `surfaceCreated(Surface)`, 2 `surfaceChanged(String, int, int, int)`, 3 `surfaceDestroyed(String)` — 홈 위젯(기존 `StockMapPreview`)
  - **22 `surfaceCreatedSplit(Surface, width, height)`**, 15 `surfaceChangedSplit`, **16 `surfaceDestroyedSplit(String)`**, 17 터치(`MotionEvent`), 20 분할 상태바 표시 — 분할 화면
  - 18 `surfaceCreatedEx(package, class, Surface)` — class가 `launcher`/`advanced_launcher`/`ev2`/`nmode`일 때 서로 다른 위젯 화면
- 구현: `StockMapPreview(…, split=true)`가 22/16을 쓴다. 분할 화면의 `지도` 페이지가 보이면 페이지가 `K8Host.updateSplitBounds`로 위치를 알려 주고, 그 자리에 내비 화면을 올린다. 누르면 순정 내비 열기, 오른쪽으로 밀면 닫기, 위아래로 밀면 위젯 바꾸기.
- 차에서 볼 것: 분할 화면 지도에 내비 그림이 뜨는지(`logcat -s K8HomeMap`, 내비 쪽 `Split AIDL : surfaceCreatedSplit()`), 길안내 중 회전 화살표가 보이는지, 순정 분할 화면과 동시에 쓸 때 서로 빼앗지 않는지, 테마를 닫은 뒤 순정 분할 화면이 정상인지.

### 2. 자동차 라이브러리의 읽기 전용 관리자 (다음 후보)
`automotive.jar`(이미 공조에서 쓰는 라이브러리)에 리스너·조회 메서드가 있다. 일반 앱 허용 여부는 공조처럼 차에서 확인해야 한다.
- `com.hkmc.hev.HEVManager`: `onBatteryState`, `onHevVehicleInfo`, `onHCU051~054`(에너지 흐름 신호로 추정), `onMyDrivingModeChanged`, `getHEVInfo(int)`, `getDrivingHistory()` → 하이브리드 에너지 흐름·배터리 화면 후보. 번호 뜻은 `HEVManager$HEVFlag`, `$HCU_05x` 상수 대조 필요.
- `com.hkmc.tmu.TMUManager`: `getCarSpeed()`, 문·에어백 리스너.
- `com.hkmc.bcm.BCMManager`: 문, 기어, 램프, 배터리, 시트 통풍 리스너.
- `com.hkmc.usm.USMManager`: 거리·속도·연비 단위.
- `com.hkmc.split.*Manager`: 각 순정 앱이 분할 화면 쪽으로 **보내는** 통로라 테마가 받을 수는 없다.

### 3. 여전히 안 되는 것
- 회전·차선 **숫자 정보**를 방송으로 받는 길은 없다. 위 1번처럼 내비가 그린 화면을 받아 보여 주는 것까지가 주입 없이 되는 범위다.
